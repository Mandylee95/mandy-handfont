Format

Install on Mac: double-click the file → “Install Font”. Windows: right-click → “Install”. The same file works on both and includes every script you’ve drawn. .ttf is the safest choice if you’re not sure — it’s the format Windows and Adobe apps expect most often. Each download gets a unique name so old installs never get in the way. If you drew only one case, the other automatically reuses your letters.

Your work auto-saves as you draw — in this browser, and to your account once you’re signed in, so you can continue on any device.
